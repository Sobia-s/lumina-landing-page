Common questions

FAQ

Do I need to know React to use Lumina?

Basic JavaScript knowledge is enough. All content lives in config files — you don't need to touch React components to customize text, images, colors, or links. The docs guide you through everything.

Can I use Lumina for a freelance client?

Yes — the license covers one personal or one client project. For multiple client projects, purchase additional licenses. Lumina's Services page + contact flow makes it a natural fit for freelance sites.

How does the contact form work?

The form includes full validation with success/error feedback. To send real emails, connect Formspree or EmailJS — step-by-step instructions are in the documentation.

What images are included?

Placeholder images are included for easy replacement. The live demo uses Pexels stock photos for demonstration — these are not included in the purchase.

How do I deploy it?

Deploy to Vercel or Netlify in minutes. The documentation includes step-by-step deployment guides for both platforms — it's the fastest part of the whole setup.

Is support included?

Yes — email support is included for installation help and usage questions. Response within 24–48 hours on business days.
