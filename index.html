FAQ

Do I need to know React to use Lumina?

No, React knowledge is not required. Basic JavaScript knowledge is enough. All content is managed through simple config files, so you never need to touch components. Just add your content, and the system handles the structure and design for you.

Can I use Lumina for freelance clients?

Yes, each license is valid for one project, either personal or client use. For additional projects or clients, please purchase extra licenses.

Can I customize everything?

Yes, you can fully customize text, images, colors, and sections through config files without modifying core components.

What do I get after purchase?

You get the complete Lumina React portfolio system, ready to run and deploy, along with setup instructions and documentation.

How do I deploy it?

You can deploy it easily using Vercel or Netlify. Step-by-step deployment instructions are included in the documentation.

Is support included?

Yes, email support is included for installation and usage help. Response time is typically 24–48 hours on business days.
