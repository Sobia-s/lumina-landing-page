FAQ

Do I need to know React to use Lumina?

Basic JavaScript knowledge is enough. All content lives in config files, no touching React components to customize text, images, colors, or links.

Can I use Lumina for a freelance clients?

Yes — the license covers one personal or one client project. For multiple clients, purchase additional licenses.

How does the contact form work?

Full validation with success/error feedback. Connect Formspree or EmailJS to send real emails — instructions included in the docs.

How do I deploy it?

Deploy to Vercel or Netlify in minutes. Step-by-step guides for both platforms are in the documentation.

Is support included?

Yes — email support for installation help and usage questions. Response within 24–48 hours on business days.
